# Golden fixtures

Self-owned regression fixtures for the schematic builder and map.dat
writer. Inputs (`grid-*.json`, `selection.json`) and expected outputs
(`nbt-*.nbt.gz`, `materials-*.json`, `mapdat.dat.gz`) are generated by
the pipeline itself and committed; the tests in
`core/tests/golden.rs` compare current output against them.

Regenerate after a deliberate behavior change:

    cargo test -p arachne-core --test golden bless_fixtures -- --ignored

Re-blessed 2026-08-27: full-layer fixture lost its per-step pillar
extras when `all_optimized` was removed (support_count 27525 to 16640,
one filler per position). The `allopt` fixtures were deleted with the
mode.

Re-bless only when a diff is intended and understood; the point of the
suite is that unintended diffs fail.

History: until 2026-08-15 these fixtures were captured from
rebane2001/mapartcraft's workers (1.20, DataVersion 3463) and pinned
output parity during the port. Parity was retired 2026-08-13
(minecraft#17); the suite was re-blessed from Arachne's own output
once the builders deliberately diverged (step-aware supports,
minecraft#26). The original cross-check served its purpose and is
recorded in git history.
