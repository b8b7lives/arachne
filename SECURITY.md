# Security

Arachne runs entirely in your browser. There is no backend and no
account, and nothing you load is stored or sent anywhere. A security
problem would therefore be in the static site at
https://b8b7.live/arachne/, in the service worker, in the files the
tool exports, or in the code in this repository. Problems in Minecraft,
Litematica, WorldEdit, or your browser belong with those projects.

## Reporting

Please mail arachne@b8b7.live rather than opening a public issue. The
same address is published at https://b8b7.live/.well-known/security.txt.
It helps to include the build id from the page footer, what you did,
and what you saw.
