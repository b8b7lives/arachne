Import / export

bring a palette in

Takes a mapartcraft palette: the MapartcraftPalette.txt they export, a link containing ?preset=, or the preset string itself. It also takes a settings file exported here. Colors the palette leaves out are switched off, the same as they are over there.

take yours out
  • A link carries the palette only: which colors are on and the block picked for each.
  • A settings file carries everything on this page, including your loadout and picture settings.

Palette

A map picture can only use these 61 colors. Every block offered for a color renders the exact same pixel, so your pick changes what you mine and haul. The picture looks identical either way. Arachne preselects the cheapest one to break and get back with your tools (highlighted green). Click another block to override, or × to drop the color from the palette entirely. In table view, each row has a dropdown with the same choices.

Summary

Download

Drop the file into your world's data folder, then /give @p filled_map[map_id=0] (1.20.5 and later) or filled_map{map:0} before that. No blocks are placed, so block and teardown settings don't apply.

Every schematic includes a reference row along its north edge. Without it the map's top row renders a shade too bright, a visible line across the top of each panel. Each split panel gets its own; tick "panels reuse the row above" if you would rather they not overlap a panel you have already built.
